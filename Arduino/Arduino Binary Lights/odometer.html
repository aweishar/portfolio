Use it like the real project

  1. Enter digits using the remote or your keyboard.
  2. Press ▶Ⅱ / Enter to display the number.
  3. Press ⏻ / Escape to clear the entry and lights.

The lights keep their previous value while you enter the next number. Displaying a number resets the entry to zero.

About this recreation

This browser simulation follows the supplied Arduino sketch, including its entry rule: when the pending number is already 409 or greater, the next digit sets it to 4095. For example, entering 4090 displays 4095 when finalized.

The remote uses a common Arduino kit layout. Only the digits, power (Clear), and play/pause (Display) are used by this project; the other buttons are inactive.

Bit values run from 2048 on the left to 1 on the right. The sketch defines pin order; the physical orientation is represented here in standard binary reading order.
